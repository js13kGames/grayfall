Grayfall

Grayfall is my first game project - a small platformer about a unicorn on a mission to restore the colors stolen by the color thief.

Defeat bosses, unlock new abilities, explore the level, and make your way to the final battle.

Controls

A / D or ← / → - Move
Space - Jump
X / J - Attack
K / C - Dash

Restore the rainbow :)
