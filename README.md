# Grayfall

A minimalist pixel-art platformer built for **js13kGames 2026**.

The Color Thief has stolen the rainbow, leaving the world gray. Play as a unicorn, restore lost colors, unlock new abilities, and defeat the Color Thief.

## Gameplay

**Explore → Fight → Restore Color → Unlock Abilities → Continue**

### Levels

* 🔴 **Flame Beast** - restores RED → unlocks Fireball
* 🟠 **Dash Fiend** — restores ORANGE → unlocks Dash
* 🌈 **The Color Thief** — restores the remaining colors

## Features

* Pixel-art side-scrolling platformer
* 3 compact levels
* Pattern-based boss fights
* Fireball and Dash abilities
* Procedural pixel-art graphics
* HTML5 Canvas
* Vanilla JavaScript
* No external assets or libraries
* Designed for the **13 KB js13kGames limit**
